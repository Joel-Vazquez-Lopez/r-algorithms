# R Algorithms

Algorithms, search, and computational methods implemented in R.

This repository collects algorithmic projects developed while studying
artificial intelligence, algorithms and data structures, and related
computational methods.

The focus is on implementing algorithms from first principles,
understanding their mathematical foundations, and evaluating their
behaviour experimentally.

## Projects

### Delivery Man — A* Search

Route planning on a dynamically weighted grid using A* search.

The implementation combines accumulated traversal cost with a Manhattan
distance heuristic to find minimum-cost routes while road conditions
change over time.

**Topics:** A* search · heuristic search · graph traversal · shortest paths · dynamic edge costs

**Language:** R
